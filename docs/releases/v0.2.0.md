# v0.2.0

## New features

- Added multi-device session management with device platform classification, primary/secondary device handling, secondary-device limits, and phone-session replacement.
- Added QR login and secondary-device OTP verification flows.
- Added room message pinning: pin, unpin, and list pinned messages.
- Added polls with single or multiple choices, expiration support, poll retrieval, and voting.
- Added room schedules, reminders, monthly calendar views, and schedule deletion.
- Added room activities for tasks, attendance, checklists, billing, and general activities, including participant progress and completion/confirmation status.

## Improvements

- Extended message, device-session, room-event, and room-activity models and database migrations.
- Added internal event-bus events for authentication, message, and room-related workflows.
- Added Redis service configuration to Docker Compose and Redis application configuration.
- Updated authentication tests and device repository mocks for the updated device flow.

## Documentation

- Added design documentation for user presence, typing indicators, and horizontally scalable realtime delivery.

## Notes

Redis infrastructure and realtime design documentation are included in this release. WebSocket presence, typing indicators, and cross-instance realtime delivery are not implemented yet.
